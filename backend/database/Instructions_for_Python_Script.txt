This script is structured specifically for an attendance use case. It loads known student images from a folder, captures live webcam video, runs the recognition model on every second frame to prevent lagging, and logs successful check-ins to an Excel-compatible CSV file with a timestamp.
Prerequisites
First, make sure you install the required libraries in your terminal:
bash
pip install face_recognition opencv-python pandas
Use code with caution.
Project Directory Setup
For this script to run seamlessly, organize your project files like this:
text
classroom_attendance/
│
├── main.py                  <-- Save the script below as this file
├── attendance.csv           <-- Automatically generated by the script
│
└── known_students/          <-- Create this folder and drop student photos here
    ├── John_Doe.jpg
    └── Jane_Smith.jpg
Use code with caution.
Note: Name the image files exactly how you want the student's name to appear in the attendance log (e.g., First_Last.jpg).

How to Test Your Script
1. Take a clear picture of yourself with your phone or laptop camera.
2. Put the picture inside the known_students/ folder and name it Your_Name.jpg.
3. Run the script: python main.py.
4. Look at the camera. Once it outlines your face in green and draws your name, hit q to exit and look at the newly generated attendance.csv file in your project folder.
